Your Mac, mapped

Liberator moves an OpenCore Mac to macOS 27 and sets up the NullMoth driver there. Keep the USB stick or disk OpenCore started this Mac from plugged in: Liberator changes the settings on that one.

Looking...one second

Prepare for Golden Gate (macOS 27)

From macOS 15 or 26, Prepare for Golden Gate does the whole move to macOS 27 in one run. It checks this Mac, downloads what it needs (about 27 GB, most of it macOS 27 from Apple), builds the startup files macOS 27 needs on this PC, puts macOS 27 on its own new volumes beside the macOS you use now, sets it up, and then makes the macOS 27 startup files the default. It needs about 102 GB free while it runs and asks once before it starts. The new system starts with your account brought over, unless you tick Set up as a new Mac instead: then it starts at Apple's setup like a new Mac. Your current macOS and its startup files are kept: Cancel Golden Gate puts them back. If it stops, press the button again: what is already done is not done twice. Keep your OpenCore USB stick until macOS 27 is running. Wi-Fi and Bluetooth do not work on macOS 27 yet.

Remove macOS 27 puts the startup files back and erases the macOS 27 that Liberator installed, with everything in it; it asks first. The downloads are kept in a folder only the system can open and are checked again every time they are used, so a try that fails does not download them again. Clear downloads frees that space.

NVIDIA driver

  1. Get the driver.
  2. Look before touching anything. Liberator reads your OpenCore config and lists every change it would make. Nothing is changed. (macOS asks for your password.)
  3. Install. Backs up your OpenCore config, makes exactly the changes listed, and installs the driver.
  4. Restart. If macOS says a system extension was blocked, open Privacy & Security, click Allow, and restart once more.

What Liberator is doing



Open the log folder





Updates


Liberator checks for the newest NullMoth driver and the newest Liberator app. The app updates itself and reopens. Every download is checked against its published SHA-256.


   


Early updates. A new driver goes first to people who turn this on, and reaches everyone once their machines show it made nothing worse.


  



If something goes wrong after you restart


In the OpenCore boot picker choose 1401: Remove NVIDIA driver, then your macOS disk. The driver is removed, this Mac restarts, and it comes back as it was before the install, OpenCore config included. The screen may stay dark until that second restart.











Check my EFI


Checks the OpenCore setup this Mac starts from against the settings that work on PCs like yours, and explains anything that needs changing, with the steps. It only reads: nothing is changed. Asks for your password once.













Tools


Mount EFI


The EFI partition holds your boot setup. Liberator finds the one this Mac started from, mounts it and opens it in Finder. Asks for your password once.


 


Startup text (verbose mode)


Shows what macOS is doing while it starts instead of the Apple logo. Useful if a start hangs. Takes effect at the next restart.


 


Built-in screen brightness (laptops)


For a laptop whose built-in screen is wired to the NVIDIA GPU (MUX set to Discrete or dGPU). It lets the driver read the panel's brightness controls from the laptop's firmware. It is off by default because that call stopped some PCs at GPU start; if yours stops there, choose 1401: Start once without NVIDIA driver in the boot picker and turn it off here.


 


HiDPI (Retina) modes


Lets HiDPI "looks like" sizes work, for example 1920 x 1080 on a 2560 x 1440 screen, including ones added with a tool such as BetterDisplay. Without it such a size is refused and switches back. The driver draws the desktop at up to twice the screen's size, which uses more video memory. Takes effect at the next restart.


 


Microphone and camera


With the driver installed, macOS does not ask before an app uses the microphone or camera, so apps such as Discord get silence and never appear under Privacy & Security. Pick the app here to allow it the microphone, camera and screen recording.


 


Map my GPU (experimental)


A few minutes of measurements on this Mac's GPU: what Metal reports, a correctness check, memory and compute speed, and small test shaders. Nothing is changed and no display mode is touched. The result goes in the log folder, and Send logs uploads it so the next driver can be tuned for your card.

Something still wrong?


Send logs


Liberator sends what it did, the driver's state, crash reports, OpenCore's startup logs and a numeric device map, with names, serial numbers and addresses removed. You get a report ID to post in the NullMoth Discord.


 


Record the flicker: press it while the screen flickers. Liberator records 20 seconds of how the driver puts frames on the display and sends it with your logs.




Crash report


If the driver ever crashes this Mac, Liberator asks at the next login whether to make a report. It is a text file on your Desktop with your hardware and what failed, with your name, your Mac's name, serial numbers, addresses and file paths taken out. Liberator never sends it by itself.




   


Optional diagnostics


Capture is unavailable in this version. Send logs still collects hardware, kernel and panic evidence. No security settings have changed.


 


Checking availability starts no trace. A saved receipt needs its own session upload permission and a separate Send logs confirmation.
